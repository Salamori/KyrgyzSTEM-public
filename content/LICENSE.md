# Content licensing

The MIT License in the repository root covers the code. It does not cover this `content/`
folder.

- `problems/sample-sum/` is synthetic demonstration data that shows the package format. It
  is released under CC BY 4.0. It is not a real educational problem.
- `curriculum.toml` is project-authored metadata: the list of topics, tags and
  prerequisites that the application needs. It was added in this project, drafted with AI
  assistance, and cites no external source. No license is granted for it yet.
- Each problem declares its own license in `problem.toml`. A declared license applies only
  to material that the contributors have the right to license. Nothing here grants rights
  to third-party problems, contests, books or websites.

Problems from the private development repository are not included. They will be added only
after a person has confirmed the rights for each one.

To report a rights concern, use the repository's private vulnerability reporting form
(Security tab, "Report a vulnerability").
