# Пример суммы

Этот синтетический пример показывает формат материалов. Даны `n` целых чисел. Найдите их сумму.

## Входные данные

В первой строке находится целое число `n` (1 ≤ n ≤ 1000).

Во второй строке находятся `n` целых чисел `a_i` (0 ≤ a_i ≤ 1000).

## Выходные данные

Выведите одно целое число: сумму чисел.
